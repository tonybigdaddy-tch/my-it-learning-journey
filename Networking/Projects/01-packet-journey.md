# Project 01: How a Packet Travels Across a Network

## Project Goal

This project demonstrates how data travels from a source computer to a destination computer across a network.

## Network Scenario

The communication will involve:

- Source Host (PC A)
- Ethernet connection
- Network switch
- Router
- Network switch
- Destination Host (PC B)

## What I Want to Demonstrate

This project will explain and visualize:

- How data is encapsulated as it moves down the networking layers
- The role of TCP/IP
- IP addressing
- MAC addressing
- Ethernet frames
- How a switch forwards frames
- How a router forwards packets between networks
- Decapsulation at the destination host

## Practical Demonstration

A short visual animation will eventually be created to demonstrate the journey of a packet from PC A to PC B.

## Learning Outcome

By completing this project, I aim to demonstrate my practical understanding of how data moves through a network from a source host to a destination host.
