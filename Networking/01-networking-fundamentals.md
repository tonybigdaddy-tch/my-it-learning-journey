## 🌐 What I Have Learned So Far

### 1. What is a Network?

A computer network is a group of connected devices that can communicate with one another and share resources.

These devices can include computers, phones, printers, servers, switches, routers, and other network devices.

### 2. Client and Server

I learned that a client is a device or application that requests a service, while a server is a device or application that provides a service.

An important thing I discovered is that a computer does not have to be permanently a "client" or permanently a "server."

Depending on the software and the task being performed, the same computer can act as a client in one situation and a server in another.

### 3. The OSI Model

The OSI model provides a way of understanding network communication by dividing it into seven layers:

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

I am learning to use the OSI model as a way of understanding what happens to data as it moves through a network.

### 4. MAC Addresses and IP Addresses

I learned that a MAC address and an IP address serve different purposes.

A MAC address identifies a network interface at the Data Link layer, while an IP address is used for logical addressing at the Network layer.

IPv4 addresses are 32 bits long, while IPv6 addresses are 128 bits long.

### 5. Ethernet and Broadcast

I learned that Ethernet uses MAC addresses for communication within a local network.

A broadcast is a message intended for all devices within the local broadcast domain.

I also learned an important rule:

> Routers do not normally forward Ethernet broadcasts from one network to another.

This helped me understand why different networks are separated into different broadcast domains.

### 6. ARP

ARP (Address Resolution Protocol) helps a device discover the MAC address associated with an IPv4 address on the local network.

For example, if a computer knows the IP address of another device but does not know its MAC address, it can use ARP to discover it.

### 7. Switching and Routing

I learned that switches primarily operate within a local network and use MAC addresses to forward Ethernet frames.

Routers connect different networks and use IP addresses to make forwarding decisions.

This helped me understand the difference between communication within a network and communication between different networks.
